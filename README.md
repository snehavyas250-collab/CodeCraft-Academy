# CodeCraft Academy

A modern responsive educational landing page built using HTML5, CSS3 and JavaScript.

## Features

- Responsive Design
- Dark/Light Mode
- Glassmorphism UI
- Course Table
- Student Registration Form
- HTML5 Video & Audio
- Scroll Reveal Animation
- Loading Screen
- Accessibility Improvements

## Technologies

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts (Manrope)
